## 👩‍💻 About Me

I'm a **Robotics Engineer** with a multidisciplinary background in robotics, software development, artificial intelligence, and mechanical engineering.

My work spans **autonomous navigation, robot manipulation, simulation, control, embedded systems, computer vision, and machine learning**.

During my Master's thesis internship at the **Istituto Italiano di Tecnologia (IIT)**, I worked on the simulation and low-level control integration of a cable-driven robotic manipulator, using **ROS2, Gazebo, URDF, and CAN bus**.

Alongside my robotics background, I have professional experience in software development, document automation, database queries, API integration, and technical debugging.

I'm particularly interested in the intersection of **intelligent software, physical systems, and real-world engineering challenges**.
